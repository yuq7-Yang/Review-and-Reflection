# 周复盘框架

## 定位

一周太短，谈"能力成长"是虚的。周复盘只解决两件事：**这周哪里慢了，下周怎么快**。

不写心路历程，不写感悟。写事实、卡点、动作。

## 结构

```markdown
# 周复盘 2026-W45（11.02–11.08）

**一句话**：这周把 X 从 0 推到能开会讨论的程度，但 Y 一直卡在等对方回复。

**最大收获**：…
**最大问题**：…

## 一、本周交付

| 事项 | 产出物 | 给谁 / 去向 | 状态 |
|---|---|---|---|
| 招商手册初稿 | 招商手册_v1.docx | 报给部门负责人，未回 | 待反馈 |
| 渠道名单整理 | 渠道台账.xlsx | 自己用 | 完成 |

只列有实物或有结论的。"推进中"的放到第二节。

## 二、卡在哪

### 1. 报价页被否两次
- **现象**：第一版按成本加成报，第二版按竞品对标报，都不行
- **根因**：开工前没确认报价逻辑是给谁看的——给客户看还是给内部审批看
- **下次怎么改**：凡涉及对外口径的文档，动手前先问一句"这份要给谁、用来干什么"

（每条都按 现象 / 根因 / 下次怎么改 三段写。写不出根因的，直接写"根因不明，下周找 X 问清楚"——不要硬编。）

## 三、能不能更快

| 这周的做法 | 更快的做法 | 沉淀成什么 |
|---|---|---|
| 每次手动整理联系人 | 建一次台账，后续增量更新 | 渠道台账，模板固定下来 |

只有一条也行。没有就写"本周无"，不要凑。

## 四、上期兑现

| 上期承诺 | 兑现情况 |
|---|---|
| 把平面图定稿 | 未完成，卡在等设计出图 |

## 五、下周只做 3 件

1. **把报价页定稿** — 验收：拿到明确书面意见，不管是通过还是否
2. **跟对接人确认返点口径** — 验收：有会议纪要或书面确认
3. **把平面图催出来** — 验收：设计给出可评审版本

超过 3 件说明没在选，是在许愿。
```

## 追问清单

素材不足或某项空着时，从下面挑，一次最多问 3 个：

1. 这周有哪件事返工了？第一次为什么会做错？
2. 有没有事卡在别人身上超过两天？催了没有，怎么催的？
3. 哪个环节你这周做了第二遍？（做第二遍的地方，就是该固化成模板的地方）
4. 有没有一件事做完了，但你说不清为什么要做？
5. 下周如果只能推进一件，是哪件？

## 判断标准

写完后自检：

- **交付项能不能被验证？** "推进了招商工作"不合格；"招商手册 v1 报给部门负责人"合格
- **卡点有没有根因？** 只写"时间不够"等于没写，要问清是被什么占掉了
- **下周 3 件事有没有验收标准？** "跟进 X"不合格；"拿到 X 的书面确认"合格
- **有没有一句是在替自己找理由？** 有就删掉

## 篇幅

正文控制在 800 字以内。周复盘写长了，说明把月复盘的事写进来了。
